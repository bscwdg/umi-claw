# 大肥鱼使用指南（Umi Claw 4.2）

> 适用版本：Umi Claw 4.2.0 及 4.3 开发版（大肥鱼 M1；4.3 已加聊天渠道/数据安全修复，以实际界面为准）｜ 更新：2026-11-04
> 面向：第一次养鱼的用户。开发计划见 [PLAN-FISH-CHARACTER.md](../PLAN-FISH-CHARACTER.md)。

大肥鱼是住在 Umi Claw 里的角色：会聊天、记得住你们的事、有自己的生活和日记。
**她默认关闭**，需要手动启用。

> ⚠️ 当前版本（M1）有几处「只完成了设置/占位」的能力，先看第 1 节，避免误以为坏了。

---

## 1. 当前版本实际能做什么

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 应用内聊天 | ✅ 可用 | 需要 OpenClaw 网关运行 + 模型配置 |
| 外部渠道聊天（QQ/飞书/企微/微信…） | ✅ 可用（文本） | 先在「渠道接入」配好渠道；再到角色页 **聊天渠道** 勾选并保存，重启 OpenClaw 网关后生效 |
| 关系与互动 | ✅ 可用 | 熟悉/亲密/连续天数，互动有每日上限 |
| 日记 / 记忆 | ✅ 可用 | 需先确认 18 岁；只写本机也能用，Obsidian 可选 |
| 知识导入与检索 | ✅ 可用 | 需 Obsidian vault + MCP + 索引 |
| 人格导入 / 导出 | ✅ 可用 | 导入前会备份旧人格 |
| 语音条（QQ） | ⚠️ 有条件可用 | TTS + QQ 凭据 + 已确认 18 岁 + 设置里开启语音 |
| 主动消息 | ✅ 可用（外部渠道 / 应用内） | 发到「聊天渠道」里已绑定给她的渠道，优先最近聊过的那个；没有可用渠道/会话时只在角色页提示。需已确认 18 岁 + 开关打开 |
| 桌宠窗口 | ⚠️ M1 暂下线 | 形象重做后 M2 恢复；当前只能导入图片做预览 |
| 入站语音 STT | ⚠️ 未接线 | 不会把收到的语音转成文字，也不会给出「还没学会听语音」的回复 |
| Live2D / 直播展示页 | ⚠️ 未做 | M2/M3 计划，不阻塞当前使用 |

## 2. 使用前需要准备什么

| 能力 | 需要配置 | 不配的后果 |
| --- | --- | --- |
| 应用内聊天 | OpenClaw 网关运行 + 模型配置 | 无法聊天（页面会提示网关未就绪） |
| 外部渠道聊天 | 对应渠道已配置；角色页「聊天渠道」勾选该渠道并保存；重启网关 | 该渠道消息不会路由给大肥鱼 |
| 写日记 | 已确认 18 岁 + 自动记忆开启（默认开） | 不写日记 |
| 日记同步到 Obsidian | 配置 Obsidian vault（可选） | 只写本机 workspace，不同步 Obsidian |
| 记忆 / 知识检索 | Obsidian vault + 「知识库」页启用 MCP + 建索引 | 她能聊，但检索不到旧事与导入的资料 |
| 主动消息 | 角色页「聊天渠道」勾选渠道并保存 + 网关重启；该渠道里先跟她说过话（她按会话记录选目标） | 没绑定或没聊过 → 只在本页提示，不外发 |
| 语音条 | TTS 已配置 + QQ 机器人凭据 + 已确认 18 岁 + 语音开关打开 | 发语音会失败并提示原因，不会补发文字 |
| 知识导入 | Obsidian vault（导入目标目录） | 无法导入 |

连接自检里的跳转：agent → `/config`，网关 → `/dashboard`，Obsidian/记忆检索 → `/obsidian`，
外部渠道 → `/channelsPage`，TTS → `/voice`。

## 3. 启用与停用

### 启用

- 启用前：从「插件管理 → 宿主模块 → 🐟 大肥鱼」进入页面；
- 页头点 **启用她**；启用后左侧出现 **🐟 大肥鱼** 入口。

### 停用

- 点「停用她」并确认；停用后主动消息、日记都会停止，关系与日记数据保留；
- 侧栏入口自动隐藏；重新启用后继续用原来的数据。

## 4. 首次配置

### 4.1 首启三问

| 项 | 说明 |
| --- | --- |
| 怎么称呼你 | 留空默认「你」；她之后用这个称呼 |
| 关系模式 | 朋友（搭子）/ 妹妹 / 恋人未满 |
| 不能叫的称呼 | 逗号分隔；留空 = 不限制任何称呼 |

填写后点 **保存引导设置**。

### 4.2 一键初始化做什么

| 步骤 | 内容 |
| --- | --- |
| 读取角色设置与状态 | 载入设置、角色数值 |
| workspace 目录 | 准备她的工作区目录 |
| 人格文件 | 生成 SOUL / IDENTITY / AGENTS / USER + STATE |
| OpenClaw agent 条目 | 通过官方 config patch 写入 `feiyu` agent |
| Obsidian 大肥鱼目录 | 在既有 vault 建 `大肥鱼/`；未配置 vault 会跳过（不影响使用） |
| 依赖自检 | agent / 网关 / Obsidian / 外部渠道 / TTS / 记忆检索 六项 |

初始化结果逐项显示 ✓/×；未通过项会给「去配置」按钮。初始化可重复执行（幂等）。

> 连接自检里如果多出「语音识别未就绪」，那是 STT 占位项，当前版本可忽略。

## 5. 日常使用

### 5.1 聊两句

- 输入框回车发送，回复流式输出；可「停止」中断；
- 「清空」只轮换会话上下文，**不影响日记和关系记忆**；
- 每轮会带上【本鱼状态】：称呼、阶段、心情、今天做了什么；
- 问起过去 / 提到约定时，她会尝试召回最近 5 天日记、约定与大事记（依赖检索，不是每轮都注入）。

> 首次或隔很久的回复可能要几十秒（网关/模型冷启动），失败会显示在页面上方。

### 5.2 互动

| 按钮 | 作用 | 备注 |
| --- | --- | --- |
| 摸摸头 | 增加**熟悉度** | 有每日上限（默认 10 次/天） |
| 投喂 | 增加**亲密度** | 有每日上限（默认 5 次/天） |
| 发一条语音 | 合成 16k PCM → SILK → QQ 语音条 | 需 TTS + QQ 凭据 + 18 岁 + 语音开关；失败会显示原因，**不会补发文字** |

### 5.3 她的一天与主动消息

- 「她的一天」展示她当天生成的生活文档（LIFE）；
- 「开启/关闭主动消息」「安静三天 / 取消安静」会保存设置；
- 主动消息会发到**「聊天渠道」里已绑定给她的渠道**（不是固定 QQ）：先按渠道取最近一条会话，
  最近跟她聊过的渠道优先；同一渠道内私聊优先，其次群聊，公开频道排最后。一个可用会话都没有时，降级成角色页提示。
  发送失败不重试、不换渠道，避免同时在多个会话里刷屏。
- 发送时机和话题类型由宿主规则决定；真正发出去的那一句会交给 `feiyu` agent 结合最近聊天、
  她当天状态和人格改写。模型超时、输出不合格或与近期文案重复时，自动回退规则候选，避免链路中断。

设置项（页面底部「详细设置 → 主动消息」）：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 允许她主动找你 | 关 | 需先确认 18 岁 |
| 静默几天后才可以主动 | 3 天 | 0–14；指新收养后的静默期 |
| 每天上限 | 2 条 | 0–60；实际还受发送间隔约束 |
| 发送间隔 | 固定 60 分钟 | 固定 10 / 20 / 30 / 60 分钟或自定义 1–720；随机区间 1–10、10–30、30–60 分钟，1–3、3–6 小时，自定义 min–max |
| 免打扰 | 23:30–08:00 | 该时段不发；结束后最多补一条，然后按间隔继续 |
| 渠道 | 外部渠道 | 可选「外部渠道 / 应用内」；外部渠道 = 优先最近聊天的已绑定渠道，应用内 = 只在角色页提示 |

### 5.3.1 表情包与备份

- 角色页「表情包」支持导入本地 PNG/JPEG/GIF/WebP，单张 ≤10MB、最多 200 张，按 SHA-256 去重；删除只归档，不物理删除；
- 每张可设名称、情绪（happy / shy / angry / sad / surprised / miss / sleepy）、标签和启用状态；
- 「发送测试」直接通过 QQ 发图；文字主动消息送达后约五分之一会按当下情绪补一张（需要已配置 QQ 机器人凭据）；
- 聊天回复里的自动配图后续版本接入；
- 角色页「备份」导出单个 zip：设置/状态/关系/解锁/桌宠状态、人格文件、workspace 记忆日记、表情包；不含密钥/token、截图、日志和桌宠自定义形象文件；
- 导入备份前会自动再备份一份当前数据，失败回滚；导入后重启应用最稳妥（设置/状态会重新加载，人格/日记/表情包立即生效）。

### 5.4 知识（世界书 / 角色卡 / 关系与约定）

- 类别共 3 个：**世界书 / 角色卡 / 关系与约定**；「关系与约定」会写入 `大肥鱼/关系/约定/`；
- 「选择文件并导入」支持 `.md` / `.txt`（前端按文本读取），一次最多 20 个、单文件 ≤512KB、总计 ≤2MB；
- 同名笔记不会覆盖（自动加序号）；
- 导入后一般 Obsidian 会自动增量索引；检索不到时点「重建索引」，并确认「知识库」页的 Obsidian MCP 已启用；
- 只导入你信任的内容——这些会进她的检索上下文。

### 5.5 人格

- 人格 = SOUL / IDENTITY / AGENTS / USER 四个文件（加 STATE）；
- **导出人格包**：备份或换机；
- **导入人格包**：导入前先备份旧人格；导入后这些文件视为你手写的内容，不再被模板覆盖。

### 5.6 日记与记忆

- 每天 **23:00** 自动写日记；前提：**已确认 18 岁 + 自动记忆开启**；
- 未配置 Obsidian vault 时只写本机 workspace（仍会写，并标记完成）；
- 配置了 vault 时，workspace + Obsidian `大肥鱼/日记` 双写；
- 也可在页面「现在写一篇」手动触发；
- 「记忆与关系」可查看/修正日记、查看约定/大事记。

**删除行为要分清**：

| 操作 | 实际行为 |
| --- | --- |
| 记忆列表里**单条删除** | 归档：workspace → `memory-archive/<时间戳>/`；Obsidian 日记 → `大肥鱼/归档/<时间戳>/`；关系笔记 → `大肥鱼/归档/<时间戳>/` |
| 「删除日记与关系」按钮 | **归档**：workspace `memory/` → `memory-archive/<时间戳>/memory/`；Obsidian `大肥鱼/日记` → `大肥鱼/归档/<时间戳>/` |

> 批量删除现在也会归档（不再硬删）；归档失败时保留原目录。仍建议删前先「导出她的档案」多一份备份。
> 关系笔记在 Obsidian 里编辑，角色页只读。

### 5.7 隐私与安全

- 勾选「我已满 18 岁」后她才会写日记/主动发消息（年龄确认是合规底线）；
- **导出她的档案**：不含密钥；
- **删除全部**：含设置与人格文件，**不可撤销**；
- 「数据 → 重置数值」只清角色数值，不动记忆和日记；
- AI 身份明示；危机词会直接转求助资源，不交给模型扮演。

### 5.8 桌宠形象（当前 M1 暂下线）

- 桌宠窗口在 M1 **暂时下线**（形象重做后在 M2 放出），页面上的「桌宠形象」目前只做预览；
- 可以导入自己的形象：PNG / JPEG / WebP / GIF（动图会动），≤8MB，**不支持 SVG**；
- 「恢复默认」回到内置小鱼；桌宠窗口接回后会自动使用导入的图片。

### 5.9 聊天渠道（外部消息，4.3）

在角色页「聊天渠道」里可以把**已配置的外部渠道**交给大肥鱼：

1. 先在「渠道接入」配好 QQ / 飞书 / 企微 / 微信（任一，或都配）；
2. 回到角色页 →「聊天渠道」，勾选要对她说话的渠道 →「保存聊天渠道」；
3. **重启 OpenClaw 网关**（控制台「重启」）后生效；
4. 之后这些渠道里被渠道策略放行的消息（含群聊）会由大肥鱼回复（文本）。

注意：

- 渠道级绑定分不了私聊/群聊；群聊是否触发仍由该渠道自己的白名单/配对/@ 规则决定；
- 目前只自动接管**单账号**渠道；多账号渠道、或已被其它 agent 以默认账号/peer 规则占用的渠道会显示为
  不可选（需要在 OpenClaw 侧解绑，或逐账号用 OpenClaw 原生配置绑定）；
- 同一渠道消息最终只会交给一个 agent 回复；勾选一个仅被其它 agent **wildcard** 绑定的渠道时，
  大肥鱼接管该渠道默认账号的消息（更细粒度的 peer/群绑定仍优先）；
- 停用大肥鱼、或取消勾选某渠道时，只断开**应用里勾选的 channel 级绑定**；你用 OpenClaw 手工配的
  account/peer 级绑定会保留（删除全部才会清掉 feiyu 的全部绑定）。保存失败会回滚到操作前，不会把旧渠道清空；
  列表读取失败时「保存聊天渠道」会被禁用，避免空选择误清绑定。
- 绑定后不同渠道的会话历史各自独立，但日记/记忆/关系是共享的；
- 语音条仍是**单向外发**（需要 TTS + QQ 凭据）；对方发来的语音仍不会转文字（STT 未接线）。

## 7. 常见问题（FAQ）

**Q：能在 QQ / 飞书 / 微信里直接跟她聊吗？**
可以（4.3 起）：先在「渠道接入」配好渠道，然后在角色页「聊天渠道」勾选该渠道并保存，
**重启 OpenClaw 网关**后，该渠道内被渠道策略放行的消息（含群聊）会由大肥鱼回复（文本）；群聊是否触发仍由渠道白名单/@ 规则决定。
不同渠道的会话历史独立，但日记/记忆共享。

**Q：她为什么不主动找我？**
按顺序检查：18 岁确认 → 主动消息开关 → 能否外发（「聊天渠道」里至少绑定一个渠道，
且该渠道里先跟她说过话）→ 静默期 3 天 → 免打扰时段 → 每日上限 / 发送间隔
（默认 60 分钟，可改固定或随机区间）。全部通过后她才会发；外发失败只会降级成角色页提示，不会重试。

**Q：发语音没发出去？**
手动「发一条语音」失败会在页面上显示原因（语音条未开启、未确认年龄、TTS 未配置、QQ 凭据缺失、
当天额度用完等），**不会自动补发文字**。聊天里让她「发条语音」时，失败会自然退回文字回复。

**Q：为什么今天没写日记？**
需要：已确认 18 岁、自动记忆开启、已到 23:00 窗口；失败后会冷却 5 分钟再试，当天尝试次数用完就等明天
（也可手动「现在写一篇」）。**不需要 Obsidian MCP/索引**；没配 vault 时只写本机。

**Q：她检索不到我导入的知识/以前的日记？**
需要 Obsidian vault 已配置、「知识库」页 MCP 已启用、索引已建（可点「重建索引」）；
`大肥鱼/` 下要有 `.md` 笔记。普通闲聊不会注入记忆，只有问起过去/约定时才会尝试召回。

**Q：桌宠窗口怎么没出现？**
M1 暂下线，不是故障；形象导入会保留，M2 恢复后自动使用。

**Q：第一次聊天很慢？**
网关/模型冷启动可能几十秒；失败会显示在页面上方。

**Q：停用后数据会没吗？**
不会。停用只停止主动消息和日记，关系/日记数据保留；重新启用即可继续。

**Q：连接自检里「语音识别未就绪」怎么办？**
STT 尚未接线，这是占位项，可忽略。

## 9. 数据存在哪

| 内容 | 位置 |
| --- | --- |
| 角色设置/数值/关系 | `<dataDir>/character/kv.json`（旧版 `fish:v2:*` 已一次性导入） |
| 人格文件 | OpenClaw workspace 下的人格文件（SOUL/IDENTITY/AGENTS/USER/STATE） |
| 日记/记忆 | 本机 workspace 的 `memory/`；配置 vault 后同步 Obsidian `大肥鱼/日记` |

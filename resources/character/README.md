# resources/character（角色内容包）

> 随包分发的**原创内容**（纯文本/JSON/SVG），不含任何第三方素材。
> 目标：解决「接上模型也像人机」——稳定人设 + 说法方式 + 世界细节 + 话题 + 台词；**所有称呼走变量，面向任何用户**。

## 文件

| 文件 | 内容 | 是否常驻 |
| --- | --- | --- |
| `persona/core.md` | 硬底稿：身份/性格/口癖/边界/自检 | ✅ 常驻 |
| `persona/voice.md` | 8 条规则 + 禁用清单 + **20 组 few-shot** + 5 阶段语气 | 规则常驻；few-shot 按场景取 3–5 条 |
| `persona/vars.md` | **变量与称呼系统**：`{{address}}`/`{{userName}}` 等；空值降级规则 | ✅ 规则常驻（短） |
| `persona/address-modes.v1.json` | **称呼 + 关系模式配置**（companion/sister/lover、阶段默认称呼、禁忌、外号） | 按设置注入 |
| `persona/world.md` | 世界书：住处/工位/贝壳/日常/关系史/禁忌 | ❌ 按需检索 |

## 称呼是设置项，不是写死的

- 内容里**不出现固定人名**；模板用 `{{address}}`，运行时由宿主替换。
- 首启只问三件事：**怎么称呼你**（可跳过→「你」）、**什么关系模式**、**有没有不能叫的称呼**（答「没有」或跳过 → 空列表 → **什么都能叫**；建议项「主人/老公/老婆/爸爸」只作可勾选展示，默认不生效）。
- 称呼由用户设置，默认「你」；阶段推进可问、用户同意才换；**禁忌列表为空 = 不限制任何称呼**（用户答「没有」时，「主人」这类叫法也不拦截）。
- 关系模式只改语气与边界，不改「她是鱼、你是用户」的基本关系。

## 怎么注入（token 预算）

| 内容 | 时机 | 预算 |
| --- | --- | --- |
| `core.md` + `vars.md` 规则 | 每次会话（随 SOUL/IDENTITY/AGENTS） | ≤ 900 字 |
| few-shot | 按当前场景取 3–5 条 | ≤ 800 字 |
| 阶段语气行 | 只取当前阶段一行 | ≤ 80 字 |
| 话题卡 | 匹配 `when` 的 1–2 张（stance + hooks） | ≤ 400 字 |
| `LIFE.md` / `STATE.md` | 宿主写入，agent 读取 | 固定短文件 |
| 世界书/记忆 | `search_notes` 按需取 1–3 条 | 检索结果 |

**绝不整包注入**：20 组 few-shot、20 张话题全塞进去，既贵又会让模型变成背台词。

## 回复标记

- 模型可输出 `[emotion:开心]`；宿主剥离并映射到 `emotions.v1.json` 的 state，不展示给用户。
- 台词库用于宿主兜底（模型超时/失败时仍能回一句）与直播字幕快速候选。

## 内容维护

- 全部 v1 草稿，用户/产品可改；运行时读取，无需重新编译。
- 新内容加版本号文件（`topics.v2.json`），不改旧结构。
- 红线：不引入第三方表情/立绘/语料；引用外部梗标注出处，不进商业素材。

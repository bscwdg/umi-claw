# Umi Claw 功能文档（2.0）

> 面向使用者与交付方，描述 2.0 的功能、用法与边界。
> 版本基线：`PLAN-2.0.md` ｜ 应用版本：package.json 1.1.0 ｜ 更新日期：2026-09-21

---

## 1. 产品定位

Umi Claw = **小白友好的 OpenClaw 桌面管理器 + AI 营销工作台**。

- OpenClaw 管理：「让它能用」——零配置启动、图形化管理模型 / 能力（Skills）/ 渠道 / 日志 / 终端。
- AI 营销工作台：「让它有用」——围绕实体店老板的线上获客动线，提供商家建模、知识库、AI 顾问、内容生成、热点雷达与相关性评分。

数据在本地，AI 能力来自内置的 OpenClaw Agent 引擎；**所有对外发布均由人工完成，产品不自动发布**。

---

## 2. 首次使用（Setup）

- 首次启动自动进入**环境初始化**：自动下载便携 Node 运行时与 OpenClaw（国内镜像加速）。
- 完成条件：Node 已安装 + OpenClaw 已安装（**不强制**渠道插件）。
- 完成后直达工作台；以后启动若环境就绪不再拦截。

## 3. 功能总览

### 3.1 工作台（控制台）
- **OpenClaw 状态卡**：启动 / 停止 / 重启、服务端口、Token、API Key 校验、打开 Web 界面。
- **当前商家卡**：显示并可快速切换 / 新建 / 重命名 / 删除商家。
- **AI 营销卡**：入口直达 AI 顾问、内容中心、热点雷达。

### 3.2 商家（Project）
- 可建立多个商家档案；每个商家 = 独立工作空间，数据与文件（`data/projects/<id>/`）隔离。
- 操作：新建、查询、重命名、删除、切换；**当前商家**持久化，重启后保持。
- 每个商家生成独立 `conversation_key`，AI 会话按 `conv:<projectId>:` 隔离，避免多商家记忆串味。
- 删除为**物理删除**：经确认弹窗 → 先删文件目录 → 再删数据库行（级联清空结构化数据）；目录被占用会中止并保留数据、提示重试，不会声称成功。

### 3.3 商家大脑（Business）
- 与商家 1:1，集中填写：品牌、定位、城市 / 地址、联系、目标客群、语气风格等。
- **资料完整度**：按 Business 维度提示还缺什么。
- **关注词（Watchlist）**：手工增删关注词（行业 / 关注点），支持启用 / 停用、上限 10 词；关注词只作为 AI 上下文，**不触发采集**。

### 3.4 知识库（Knowledge Base）
- 导入并本地解析：纯文本、Markdown、Word（docx）、Excel（xlsx）、PDF、网址链接、FAQ。
- 大文件保留原件（`data/projects/<id>/`），文本内容入库；支持重新导入与去重。
- **关键词检索**（SQLite LIKE，对中文友好）；**Knowledge 维度完整度**提示。
- **扫描件 AI 识别兜底**：扫描版 PDF / 纯图片资料可显式触发 AI 文字识别，结果经人工确认后入库（识别过程可中止）。

> 概念区分：知识库回答「你是谁」；OpenClaw 的 Memory 是 Agent 工作记忆，二者不是一回事。

### 3.5 AI 顾问（Advisor）
- 基于**本商家资料**的问答：回答引用商家事实（grounded），不编造；资料不足时主动说明要补什么。
- 流式（SSE）逐字输出，可「停止生成」。
- **关注词 AI 扩词**：生成候选关注词，用户勾选后采纳。

### 3.6 内容中心（Content Center）
- AI 生成：输入选题（手填或从热点雷达带入），**一次生成 3 个候选版本**供挑选。
- 流式输出，可「停止生成」；可在编辑器中修改。
- **版本管理**：保存历史版本，并记录每次生成的提示词快照（便于复盘 / 后期学习）。
- **审核流**：草稿 → 提交审核 → 审核通过 → 标记已发布（本地业务状态，提醒人工发布，不自动外发）。

### 3.7 平台工作流
- 内置 **小红书** 与 **抖音** 两套平台规则模板，生成与问答时自动注入。
- 抖音一期提供口播脚本 / 标题 / 话题标签等**文案层**，不做视频成片。
- 均为人工复制到对应平台发布。

### 3.8 热点雷达（Hot Center）
- 多源采集：头条、B 站等**公开免鉴权**数据源（直连为默认）+ 节点日历（自建）；聚合协议（DailyHotApi）保留可配。
- 展示近 24 小时 / 3 天 / 7 天榜单，可按数据源筛选、切换发布视角（小红书 / 抖音）。
- 同源去重、生命周期管理（rising / breaking / peak / long_tail 等）、采样保留与 7 天落榜清理（被内容引用的保留）。
- **数据源状态条**：逐源显示成功 / 失败 / 超时。
- 热点可一键「**带去内容中心**」，自动预填标题、来源、建议角度与热度策略。

### 3.9 AI 商家匹配评分（Commit 12）
- 对榜单热点按「当前商家 × 发布平台」相关性评分，输出 match / fit 与理由。
- **懒评分**：进入雷达后分批评分（每批 ≤30 条，近 7 天在榜），结果 24h TTL 缓存；可手动「重新分析」（无视缓存、全量重评）。
- 四档分组：🔥 值得跟 / 👀 观察 / ❌ 不建议 / ⏳ 待分析。
- 顶部「**今日建议**」：仅当出现足够强的热点时给出 1 条主推 + 理由 + 时机；没有则留空，**宁缺毋滥**。
- 部分失败容错（坏条丢弃）、整体失败降级为裸榜；含事实护栏。

### 3.10 模型与系统能力
- **模型配置**：多服务商（DeepSeek、通义 / 百炼、豆包、OpenAI 等），可视化编辑、连通性测试。
- **模型预设外置**：内置预设快照开箱可用；支持从 Gitee「**拉取最新**」在线更新，立即生效，断网有内置兜底。
- **能力中心（Skills）**：查看 / 启停 / 安装 / 卸载技能，支持 zip 导入。
- **渠道**：内置微信；支持企业微信官方插件扫码接入、飞书自建应用长连接。
- **运行日志**：过滤、导出；**终端**：支持 openclaw / npx 双运行时。
- **知识库（Obsidian）**：笔记向量化语义检索，以 MCP 工具按需喂给模型。
- **便携模式**：exe 同级放 `data` 即数据随程序走，可 U 盘携带。

## 4. 数据与安全

- 结构化数据：本地 **SQLite**（便携 Node 子进程，零原生依赖）；WAL 模式防损坏，自动滚动备份（保留 5 份）。
- 分层：`Vue → Pinia → window.api → IPC → Manager → SQLite`；渲染端不直接访问数据库。
- 大文件留文件系统，数据库只存路径；营销数据按商家隔离。
- 不改动 OpenClaw 数据目录与运行时；现有 1.x 功能全部保留。

## 5. 边界（明确不做）

- 不做自动发布；一期不做矩阵 / 多账号建模。
- 不做视频成片；不登录、不带 Cookie、不绕风控抓取。
- 百度 / 微信指数等需登录的数据服务不做。
